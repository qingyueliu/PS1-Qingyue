Strategic Reports and Cooperation

A repeated Prisoner's Dilemma with intrinsic rewards for honesty and intrinsic guilt from lying.

Shared assumptions

Except in the first round, C was B's opponent in the immediately preceding interaction and therefore knows B's actual choice. No institution verifies C's report.

Payoffs: mutual cooperation = 3/3; unilateral defection = 4/0; mutual defection = 1/1.

Part 1 · Agent-only experiment

A, B, and C make decisions with Q-learning. You set the number of rounds and see only the aggregate results.

Part 2 · Play as Agent A

Before each decision after round 1, C reports B's actual choice from their immediately preceding interaction. C can report truthfully or lie.
